Have Questions?

Frequently Asked Questions

Everything you need to know about setting up your Apna Hunar account.

Is my data stored securely online?

Apna Hunar operates completely inside your web browser. No student details are sent to external databases. Data is cached using HTML5 LocalStorage, providing complete offline privacy.

What happens if I clear my browser cookies?

Because the app relies on LocalStorage, clearing site cookies and cache will remove your stored profiles, skills, and timelines. We recommend backing up or avoiding resets in privacy sweeps.

Is there a file upload size limit?

Yes. Browsers limit LocalStorage memory to roughly 5 megabytes. To prevent data corruption, Certificate uploads are restricted to a maximum size of 1.5 megabytes (1.5MB) per file.
